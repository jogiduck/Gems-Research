종목 없이 후보 찾기

티커를 미리 정하지 않아도 됩니다. 저장한 시총 상한과 선택한 탐색 범위 안에서 CoinGecko 시총 순위 데이터를 직접 조회하고, 원자료 기준 후보를 추립니다. 이 전역 순위 API에는 신뢰할 수 있는 체인 분류가 없어 관심 체인 조건을 적용하지 않습니다. 후보의 체인·공식 컨트랙트는 다음 단계에서 별도로 확인해야 합니다.

키 없이도 실행됩니다. CoinGecko 시총 순위는 공개 데이터이며 API 키가 필요하지 않습니다. 배포에 앱 서버 API가 없으면 CoinGecko 공개 API로 직접 대체 조회합니다(공급자 CORS·요청 한도에 따름).

이번 탐색에서 실제 적용되는 기준은 저장된 시총 상한과 아래에서 입력한 최소 시총·거래량뿐입니다. 관심 체인, 위험 성향, 관찰 기간, 환매 비율, 목표는 후보 필터에 적용되지 않습니다. 결과는 개인화 투자 추천이 아닙니다.

공개 API 호출을 고려해 페이지 사이 약 12초 대기합니다. 12페이지는 약 2분, 100페이지는 약 20분까지 걸릴 수 있습니다. 전체 목록은 보장되지 않습니다.

조정 후 상승 전환 초입 후보

CoinGecko 시총 순위로 범위를 먼저 좁힌 뒤, 최대 12개 자산의 90일 일별 가격을 순차 확인합니다. 조정 후 반등뿐 아니라 하락 중인 조정 가능성도 따로 표시합니다. 조정 진행 표시는 하락이 더 이어질 수 있다는 뜻이며 매수 신호가 아닙니다. 규칙 기반 스크리너이지 AI 자율 판단이나 상승 보장이 아닙니다.

검색 범위는 CoinGecko 순위 페이지에 한정되며 전체 코인을 훑지 않습니다. 무료 API 한도 보호를 위해 심층 가격 이력은 종목당 하나씩 약 12초 간격으로 조회합니다. 예상 시간: 순위 페이지마다 약 12초 + 심층 확인 대상마다 약 12초. 긴 탐색은 수 분 이상 걸릴 수 있습니다.

시장·DEX 데이터 조회

CoinGecko 제공 시총 순위·전체 암호자산 시총 요약·가격 모멘텀·DEX 유동성을 확인합니다. “실시간”은 API 요청 시점의 제공자 응답을 뜻하며 거래소 틱·체결 실시간 또는 최신성 보장은 아닙니다. 각 원자료 시각과 환율 갱신 시각을 구분합니다. 높은 사용량이나 TVL은 미래에 반드시 채택된다는 증거가 아닙니다.

내 API 키 설정 (선택)

보안 안내 — 입력 전에 확인하세요. 키는 이 페이지 메모리에만 임시 보관하고 브라우저 저장소에는 저장하지 않습니다. 하지만 키를 사용하면 HTTPS를 통해 이 앱의 Vercel 서버로 전송되고, 서버가 제공자 API에 전달합니다. 앱 운영 서버는 처리 중 키를 받을 수 있으므로, 운영자와 배포 환경을 신뢰할 수 없는 사이트에서는 입력하지 마세요. 탭을 닫거나 15분간 사용하지 않으면 앱에서 키를 지웁니다. 이는 노출 위험을 줄이는 조치이지 완전한 삭제·비노출 보증이 아닙니다. API 제공자 계정의 사용량·요금은 키 소유자에게 적용됩니다. 지갑 개인키나 시드 문구는 절대 입력하지 마세요.

전체 암호자산 시장 규모와 환율

USD와 CoinGecko 원자료 KRW 값을 나란히 표시합니다. USD/KRW 환산 시세는 환율 API 기준이며, 실제 거래소 환전·송금 환율이 아닙니다. 데이터가 연결되지 않으면 한화 값을 추정하지 않습니다.

Vercel API에서 시장 요약을 불러와야 실시간에 가까운 원자료 상태를 확인할 수 있습니다.

암호자산 전체 시총 순위 — CoinGecko 페이지 조회

순위는 페이지당 최대 250개이며 제공자 범위 내 자료입니다. 시총·거래량은 USD/KRW, 공급량은 토큰 수량으로 표시합니다. CoinGecko가 분류를 제공하지 않는 분야·네트워크는 확인 불가로 표시합니다. 순위 없는 자산·제공자 범위 밖 자산을 포함한 전체 목록은 아닙니다.

페이지 1을 불러오면 CoinGecko 시총 순위와 24시간·7일·30일 변동을 표시합니다.
티커나 체인·컨트랙트 주소를 입력한 뒤 조회하세요.

무료·유료 경계: DEX Screener·DefiLlama·CoinGecko 공개 조회는 제한과 이용조건이 있습니다. CoinMarketCap·CoinGlass는 본인 키를 위에 입력하거나 Vercel 서버 환경변수에 배포자가 등록해야 합니다. TradingView는 차트 임베드이며 과거 캔들 API나 자동 매매 신호를 제공하지 않습니다.

file:// 직접 열기에서는 Vercel Functions가 없어 개별 자산·온체인·전체 시장 요약을 조회할 수 없습니다. 다만 시총 순위와 후보 탐색은 CoinGecko 공개 API 직접 조회를 시도하며, 브라우저 CORS·요청 한도에 따릅니다. 전체 기능은 GitHub에 GemsResearch 폴더를 올리고 이 폴더를 Vercel 프로젝트 루트로 선택해 배포하세요.
