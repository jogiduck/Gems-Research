# Gems Research

개인용 리서치 워크벤치. 정적 HTML은 `index.html`, 선택형 데이터 조회는 Vercel serverless function `api/research.js`가 담당합니다.

## GitHub → Vercel 배포

1. GitHub 저장소에 `GemsResearch` 폴더 안의 파일과 `api` 폴더를 함께 올립니다.
2. Vercel에서 저장소를 가져올 때 **Root Directory를 `GemsResearch`**로 선택합니다. 이 폴더 밖에 있는 별도 차계부 앱은 배포 루트에 포함할 필요가 없습니다.
3. Deploy 후 Vercel URL의 **시장·온체인 데이터** 탭에서 티커를 조회합니다. `file://`로 직접 연 HTML에서는 서버 함수가 실행되지 않습니다.
4. CoinMarketCap·CoinGlass 연결은 두 방식 중 선택할 수 있습니다.
   - 각 사용자가 **시장·DEX 데이터 조회** 탭에서 본인 키를 세션 중 입력합니다. 조회 요청 때만 HTTPS 헤더로 앱의 Vercel API에 전달되고, 서버가 해당 키로 제공자에 요청합니다.
   - 배포자가 공용 키를 쓰려면 Vercel의 **Project → Settings → Environment Variables**에서 키를 등록하고 새 배포합니다. 개인 키 입력이 있으면 해당 요청은 개인 키를 우선 사용합니다.
   - `CMC_API_KEY`: CoinMarketCap API 키. 조회 시 검증한 CoinMarketCap 숫자 ID를 함께 입력합니다.
   - `COINGLASS_API_KEY`: CoinGlass API 키. 해당 계정 요금제가 `coins-markets` API 접근을 허용해야 합니다. 공개 문서 기준 이 경로는 모든 무료 요금제에서 사용 가능하다고 가정할 수 없습니다.
5. 개인 키는 브라우저 저장소·URL·내보내기 백업에 저장하지 않으며 페이지 종료 또는 15분 미사용 시 앱에서 지웁니다. 다만 서버가 요청 처리 중 키를 받으므로, 신뢰할 수 없는 배포 주소에는 입력하지 마세요. 서버 운영자/호스팅 환경에서의 절대적 비노출이나 메모리 완전 삭제를 보장하지 않습니다. 키를 GitHub, HTML, URL, 채팅에 직접 넣지 마세요. 키 없이도 공개 출처 기능을 사용할 수 있습니다.

사용자 키 연결은 현재 CoinMarketCap 개별 시세·시총·공급량 및 CoinGlass 파생상품 시장 조회에만 적용됩니다. 언락, 홀더 집중, 온체인 가치 환원, AI 심층 분석은 키 연결만으로 제공되지 않습니다.

API 결과는 데이터 수집입니다. 자동 온체인 보안 감사, 상위 홀더 라벨링, 베스팅 계약 검증, 바이백 정책과 실제 매입 트랜잭션 대조, AI 기반 보고서 생성은 아직 포함하지 않습니다. 단일 출처의 응답이나 티커만으로 토큰 신원·투자 적합성을 확정하지 않습니다. 오류와 출처 누락은 성공으로 표시하지 않습니다.

## 시장 순위, 추세 판단, 레드팀 범위

CoinGecko 시총 순위 화면은 `/coins/markets`를 통해 최대 250개씩 조회하고, 별도의 시장 요약은 `/global`에서 가져옵니다. 전체 종목 수가 제공되지 않으므로 CoinGecko가 순위를 매기지 않은 자산이나 제공자 범위 밖 자산을 포함한 "전 세계 모든 코인" 목록이라고 보장하지 않습니다. 시총·거래량·가격과 유통 토큰 수량, FDV를 분리 표시하며, 개별 자산의 분야와 토큰 네트워크는 CoinGecko ID 상세 요청에서 자료가 제공될 때만 표시합니다. 목록의 자산명은 CoinGecko 개별 자산 페이지로 연결됩니다.

USD/KRW는 별도 ExchangeRate-API 기준환율을 사용합니다. 시장 목록 KRW는 USD 값에 해당 환율을 곱한 참고 환산이며 거래소의 KRW 호가가 아닙니다. 환율 원자료는 통상 일간 갱신되므로 초단위 환율로 취급하지 않습니다. 전체 시장 시총의 USD/KRW는 CoinGecko `/global`이 제공하는 각 통화별 원자료를 따로 표시합니다.

USD/KRW 가격은 0에 가까운 소액 자산도 0.00으로 뭉개지지 않도록 값의 크기에 따라 소수점 최대 20자리까지 표시하고, 그보다 작은 가격은 과학적 표기법으로 구분합니다. 시총·거래량은 소수점 2자리, 토큰 공급량은 최대 4자리입니다. 표시 자릿수는 원자료의 정밀도나 거래 가능 최소 단위를 보장하지 않습니다.

가격 추세는 CoinGecko의 365일 일봉 종가와 주봉 재표본(7일 간격)에서 7/30/90일 수익률, 20/50/200일선, 20/50주선, 30일 고점 대비 낙폭, 7일 저점 높임을 계산합니다. 이 규칙은 조정 진행 가능성·초기 반등·상방 전환 조건을 구분하는 설명 가능한 참고치일 뿐, 조정 종료·미래 수익·매매 신호를 확정하지 않습니다. TradingView 위젯은 차트 표시용이며 이동평균 수치를 API로 가져오지 않습니다. 이동평균 수치는 CoinGecko 이력으로 직접 계산합니다.

**바이낸스 전환 탭:** 바이낸스 Spot USDT 전체를 브라우저에서 직접 조회합니다. 24시간 거래대금 하한으로 먼저 걸러 상위 50/100/200개만 일봉 100개로 확인합니다. 조건 A(3일 내 20일선 상향돌파 + 60일 저점 대비 15% 이상 반등)·B(RSI 7일 내 30 이하 후 50 이상)·C(전일 대비 거래량 2배 이상 + 20일 박스 상단 돌파) 중 1개만 맞아도 표시합니다. 달러·래핑·레버리지 토큰은 기본 제외하며 제외 개수를 표시합니다. 분야는 행별 `분야 확인`으로 CoinGecko에서 조회합니다. Alpha 마켓은 공개 조회 주소 미확인으로 미연결입니다. 탐색 중 다른 탐색을 누르면 끝나고 자동으로 이어서 시작합니다.

**반전 점수·Day 1 점화:** 추세 판정은 반전 점수(거래량 30·VCP 25·정배열 25·박스 20, 합계 100)로 매겨 60점 이상·거래량 동반·정배열이면 `상승 모멘텀 초입`, Day 1(당일 거래량 3배+·30일 신고점 돌파, 바이낸스는 깨끗한 양봉까지 확인)이면 `Day 1 점화`로 표시합니다. 40점 미만 반등은 `일시 반등(데드캣 주의)`으로 분리해 상위에 올리지 않습니다. 목록이 비지 않도록 점수 미달도 등급과 함께 표시하고 추천도 순으로 나열합니다. Day 1 탐색은 소형·중형 크기에서 돌리면 잡음(유령 코인·초대형주)을 피할 수 있습니다. 마지막 봉은 미확정일 수 있어 다음날 재확인이 필요합니다.

**조정 후 추세전환 후보 탭:** 먼저 설정한 CoinGecko 시총 페이지와 개인 시총 상한, 선택한 시총/거래량 하한으로 표본을 제한합니다. 크기 선택(소형·중형·대형·자동)과 섹터, 달러 제외는 후보 찾기와 같은 선택을 그대로 사용합니다. 1차 조건은 30일 변화율 +5% 이하이며, 7일 변화율 양수(반등)와 음수(조정 진행)를 모두 포함합니다. 자료가 없는 자산은 심층 후보에서 제외해 개수를 표시합니다. 심층 확인 수(5/8/12/16/24개, 1개당 약 12초)만큼만 실제 365일·주봉 이력을 조회하므로, 1차 통과가 수백 개라도 나머지는 미확인으로 남습니다. 결과가 적다면 심층 확인 수를 늘리면 됩니다. 양수·음수 7일 변화율 후보를 번갈아 포함하고, 각 방향에서는 30일 변화율이 0%에 가까운 순으로 CoinGecko 365일 일봉·주봉 가격을 확인합니다. 관찰 패턴에는 조정 후 초입·초기 회복·조정 진행뿐 아니라 상승 모멘텀 조건과 초기 반등 시도도 포함되므로, 꾸준히 오르는 종목도 목록에 나옵니다. 심층 확인 수만큼만 조회하므로 결과가 적으면 개수를 늘리면 됩니다. 심층 반전 조건은 최근 30일 고점 대비 8% 이상 하락 또는 30일 수익률 -8% 이하의 조정, 양의 7일 수익률, 7일 저점 높임, 20일선 상승입니다. 현재 가격이 20일선 위면 "조정 후 상승 전환 초입 후보", 아직 아래면 "초기 회복 관찰"로 구분합니다. 현재 가격이 20일선 아래이고 7일 변화율도 음수이면 별도 "조정 진행 가능성" 결과로 보여주며 이는 하락 지속 위험을 뜻합니다. `file://` 로컬 화면은 CoinGecko 공개 가격 이력을 직접 조회하고 브라우저에서 같은 규칙을 계산합니다. 앱 API가 없는 호스팅에서 403/404/405 또는 연결 실패 시에도 공개 가격 이력 직접 조회를 시도합니다. 기준은 앱에 명시된 기술적 필터이며, 시장 전체를 훑는 AI 에이전트나 온체인·거래량 검증은 아닙니다. 순위 표본 밖 자산·자료 누락·제공자 실패는 놓칠 수 있습니다. 순위 페이지와 심층 가격 이력은 각각 약 12초 간격으로 조회하고, 실패/중단 자료는 정상 응답처럼 취급하지 않습니다. 완료 후 후보가 없으면 범위·심층 확인 수·선택 필터 조정 방법을 안내합니다.

탐색을 시작하면 버튼 바로 아래에 진행 상태, 회전 표시, 탐색 단계, 완료한 순위·이력 개수, 경과 시간과 API 간 대기 카운트다운을 표시합니다. 취소·오류·완료 상태도 구분해 알려주며, 진행률은 현재 단계의 완료량을 나타내는 대략적인 값이지 남은 시간 보장은 아닙니다.

종목을 지정하지 않은 상태에서 후보 파인더를 실행하면, 후보 목록에 아무 종목도 등록하지 않아도 사용자의 시총 상한 이하를 대상으로 최대 100페이지(최대 25,000행)를 순차 조회합니다. 이 CoinGecko 순위 기능은 공개 데이터라 API 키가 필요하지 않습니다. 진행 중에는 완료된 페이지의 후보 최대 10개를 미리 보여주고, 검색 완료 후 후보가 없으면 더 넓은 페이지 범위로 재검색하거나 선택 최소 필터를 비우는 동작을 제공합니다. 시총 상한은 자동 변경하지 않으며 사용자가 직접 확인·조정합니다. `file://` 로컬 화면에서는 CoinGecko 공개 API를 직접 조회하며, 배포 API가 연결되지 않거나 403/404/405를 반환하면 공개 API 직접 조회로 대체합니다. HTTP 429(요청 한도 초과)는 `Retry-After`를 따르거나 최대 3회 지수 대기 후 재요청합니다. 직접 조회는 브라우저 네트워크와 CoinGecko CORS·요청 한도에 따르며, 실패 시 완료된 부분 결과와 원인을 표시하고 임의 데이터를 만들지 않습니다.

후보 자동 탐색도 버튼을 누른 즉시 시각적 진행 표시를 띄웁니다. 현재 요청 중인 순위 페이지, 완료 페이지·검사 자산 수, 통과 후보 수, 달러 제외 수, 경과 시간, 페이지 사이 API 대기 카운트다운을 볼 수 있고, 취소·오류·완료 상태가 각각 표시됩니다. 진행률은 순위 페이지 기준의 대략적인 값이며 남은 시간 보장이 아닙니다. 크기 선택(소형·중형·대형·자동)과 12개 섹터(CoinGecko 분야 ID 기준, 직접 입력 가능), 달러·래핑 달러 제외가 적용되며 적용 기준과 제외 개수를 결과에 명시합니다. 섹터 ID가 틀리면 제공자 오류를 그대로 보여주고 임의 분류로 대체하지 않습니다. 결과 표는 박스 안에서 상하·좌우 스크롤되며 헤더와 자산 열이 고정됩니다. 완료 후에는 총 발견 개수와 상위 표시 개수(최대 30개)를 크게 보여주고 추천도(유동성·공급·모멘텀 합산, 정렬용 참고점수) 순으로 위에서부터 나열하며, 시총순위순으로 바꿀 수 있습니다. 추천도는 75점 이상 상·중 50점 이상·중 미만 하로 표시됩니다. 결과 행의 `12대 검증에 올리기` 버튼이나 표 위 `상위 5개 검증 대기열에 추가` 버튼으로 종목을 고르지 않아도 추천도 상위 5개를 12대 검증 대기열에 자동 등록할 수 있으며, 선정 기준(실제 적용 기준+추천도 순)과 체인·컨트랙트 미검증을 안내합니다.

후보 결과의 USD 값을 KRW로 환산하려면 별도 ExchangeRate-API USD/KRW 기준환율을 조회합니다. 서버 API 없이 실행할 때는 환율 공개 endpoint를 직접 조회하며, 환율 제공자가 실패하면 KRW는 확인 불가로 남깁니다. 선택 가능한 최소 시총·최소 24시간 거래량은 빈칸이면 제한을 적용하지 않습니다. 결과 화면에 실제 적용 기준과 적용되지 않은 프로필 기준을 명시합니다. 체인·위험 성향·관찰 기간·환매 비율은 이번 순위 선별에 적용되지 않으며 점수·추천도 아닙니다. 후보를 로컬 목록에 저장할 수 있고, 저장 시 CoinGecko ID와 시장 스냅샷만 기록합니다. 이 저장은 컨트랙트·체인 신원 검증이 아니며, 저장 스냅샷은 실시간 값이 아닙니다. 조회 실패/중단 시 완료된 페이지의 부분 결과와 범위를 명시하며, 데이터를 만들어 채우지 않습니다. 크기 선택(소형·중형·대형·자동)은 최소·상한 시총 범위를 정합니다. 대형은 상한 제한 없음으로 처리합니다. 달러·래핑 달러(스테이블·USD 접두·USD 접미·유로 스테이블·Tether 계열 포함)는 기본 제외하며 제외 개수를 표시합니다. 바이낸스 탐색에서는 법정화폐(EUR 등)도 제외하며 개수를 표시합니다. 래핑·브릿지 토큰(WBTC·BGBTC·Wrapped·Bridged 등)도 기본 제외하며 제외 개수를 표시합니다. 각 행의 CoinGecko 원문 링크는 직접 연결, CoinMarketCap은 티커·이름 대조로 직접 통화 페이지를 여는 CMC 바로가기와 덕덕고 경유 찾기, DEX 검색 링크를 함께 제공합니다. 구글 경유는 로봇 차단이 걸려 덕덕고로 바꿨습니다. 동명 티커가 있으면 이름이 가장 겹치는 종목을 고르며, 최종 신원은 열린 페이지에서 직접 확인하세요.

**연결/실시간 상태:** 상단 상태는 실제 API 응답 성공·실패에 따라 갱신됩니다. `file://`로 연 경우 시장 요약·개별 자산·DEX 등 서버 API 기능은 연결되지 않지만, 종목 없는 후보 파인더와 시총 순위는 CoinGecko 공개 API로 브라우저에서 직접 조회합니다. 직접 조회도 실패하면 오류를 표시하고 추정값이나 가짜 후보로 대체하지 않습니다. 모든 탭에 `← 이전 화면` 버튼이 있으며, 레드팀 오류 패널에도 같은 버튼이 있어 이전 단계로 돌아갈 수 있습니다. 12대 검증 탭에는 섹터 맞춤 `이 섹터로 후보 찾기` 버튼이 있어 해당 섹터로 후보 찾기를 바로 실행합니다. 배포 환경에서도 "API 응답 확인"은 요청에 제공자가 응답했다는 뜻이지 거래소 틱·체결 실시간이나 향후 지속 연결의 보장이 아닙니다. 순위/시장 조회 응답에는 `no-store`를 지정해 Vercel 공유 캐시를 끄고, 사용자 요청 시각·서버 응답 시각·원자료 제공자 갱신 시각을 분리 표시합니다. 15분 신선도 경고선은 앱의 점검 기준일 뿐 제공자의 갱신 보장이 아닙니다. 환율 자료는 통상 일간 갱신되고 90일 추세 자료는 일별입니다.

파인더는 무료 API 요청 한도에 무리가 가지 않도록 페이지 사이 약 12초 대기합니다(약 5회/분). 12페이지는 약 2분, 100페이지는 약 20분까지 소요될 수 있으며 완료 시점에 여러 페이지의 기준 시각은 서로 다릅니다. 각 자산의 CoinGecko `last_updated`를 확인하고, 긴 탐색 후에는 후보별 개별 데이터를 새로 요청해야 합니다. 외부 제공자 한도에 따라 429 또는 실패가 발생할 수 있습니다.

**예측 한계:** 앱이나 AI는 미래에 반드시 채택될 토큰·프로젝트나 수익을 알아낼 수 없습니다. 사용량·수수료·유동성·개발·보안은 현재/과거 활동의 관찰이지 미래 채택 증명이 아닙니다. 앱은 실질 데이터를 모아 사용자 선택을 돕지만, 근거가 부족하거나 출처가 충돌하면 판단 보류가 합리적 결과입니다.

레드팀 UI는 주소 미검증, 랭크/추세 부재, 출처 실패, FDV/시총 격차, 낮은 DEX 유동성 및 알려진 앱 한계를 표시하고 다음 확인 행동을 제안합니다. 수동 12대 점검의 긍정 표시는 사용자 메모입니다. HTTPS 출처와 기준 시각이 있더라도 앱은 링크 내용이나 주장을 검증하지 않으며, 둘 중 하나라도 빠지면 미검증 메모임을 분명히 표시합니다. 임계값 경고는 자동 점검 가설이지 사기/안전을 확정하는 판정이 아닙니다. 현재 분석은 상위 보유자·팀 지갑, 언락 일정, 바이백 트랜잭션, 컨트랙트 관리자 권한을 자동 검증하지 않습니다.

**배포 주의:** `api/research.js`는 사용자별 인증·요청 제한이 없는 공개 Vercel GET 함수입니다. 본인 키 요청은 제공자 사용량을 해당 키에 귀속시키지만, 이 API는 키 소유권이나 사용자 신원을 인증하지 않습니다. 키를 사용하기 전에 신뢰하는 HTTPS 배포인지 확인하고, 제공자 사용량 한도를 설정하세요. 공용 서버 키를 쓰는 배포에는 Vercel 비용 알림·제공자 할당량, 사용자 인증과 rate limit이 필요합니다.

**후보·설정 데이터 관리:** 내 기준 저장 시 시가총액 상한과 환매/소각 기준은 빈 값으로 둘 수 없습니다. 후보 검토에서 선택적으로 CoinGecko coin ID를 입력하면 저장 후보에서 시장 데이터를 다시 조회할 수 있습니다. 백업 가져오기는 프로필 숫자·선택값, 후보 필수 필드와 12개 검토 항목의 형식을 확인하며, 유효하지 않은 JSON은 현재 저장 데이터를 바꾸지 않습니다. 초기 연결 상태는 로컬 `file://` 모드 또는 배포 API 미확인으로 표시하고 실제 조회 뒤 갱신합니다.
